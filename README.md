# FH6 Tracker

**FH6 Tracker** est une application web communautaire dédiée aux joueurs de **Forza Horizon 6**.

À l’origine, le projet avait pour but de suivre simplement sa progression dans le jeu : voitures possédées, voitures photographiées, favoris, garage incomplet, etc.  
Le projet évolue désormais vers une plateforme plus complète, pensée comme un **hub communautaire Forza Horizon**, avec un vrai aspect réseau social.

L’objectif est de permettre aux joueurs de suivre leur progression, partager leur activité, interagir avec la communauté et organiser des événements en jeu.

---

## Concept

Dans Forza Horizon, suivre une collection complète peut vite devenir compliqué : beaucoup de voitures, des photos Horizon Promo à faire, des véhicules favoris à retrouver, des objectifs de complétion, et une progression parfois difficile à visualiser.

**FH6 Tracker** centralise tout cela dans une seule interface.

Le site combine deux grands aspects :

1. **Le suivi de progression personnel**
   - voitures possédées ;
   - voitures manquantes ;
   - photos Horizon Promo réalisées ;
   - favoris ;
   - wishlist ;
   - statistiques de progression.

2. **L’aspect communautaire**
   - feed de publications ;
   - posts des joueurs ;
   - likes ;
   - commentaires ;
   - abonnés ;
   - abonnements ;
   - sauvegarde de posts ;
   - organisation d’événements en jeu ;
   - classement communautaire.

FH6 Tracker est donc pensé comme un outil à la fois pratique et social : un endroit où l’on peut suivre son garage, montrer sa progression et rejoindre d’autres joueurs.

---

## Fonctionnalités principales

### Dashboard

Le dashboard sert de page d’accueil une fois connecté.

Il donne une vue rapide sur :

- le nombre total de voitures référencées ;
- le nombre de voitures possédées ;
- le nombre de voitures manquantes ;
- la progression Horizon Promo ;
- les voitures favorites ;
- l’activité récente du joueur ;
- les raccourcis vers les sections importantes du site.

Le dashboard permet de savoir rapidement où en est sa progression et quoi faire ensuite.

---

### Catalogue de voitures

Le catalogue regroupe les voitures disponibles dans le tracker.

Chaque voiture peut être suivie avec plusieurs états :

- **possédée** ;
- **photographiée** ;
- **favorite**.

Le joueur peut ainsi gérer précisément son garage et visualiser ce qu’il lui reste à compléter.

---

### Suivi du garage

Le suivi du garage permet de cocher les voitures déjà obtenues.

Cette fonctionnalité aide à répondre rapidement à une question simple :

> Quelles voitures me manque-t-il encore ?

Le site peut ensuite afficher les voitures manquantes et aider le joueur à prioriser sa progression.

---

### Horizon Promo

FH6 Tracker permet également de suivre les voitures déjà photographiées.

Cette partie est utile pour compléter les objectifs de type **Horizon Promo**, où le joueur doit photographier les voitures du jeu.

Le tracker permet donc de voir :

- les voitures déjà photographiées ;
- les photos restantes ;
- le pourcentage de progression photo.

---

### Favoris

Les joueurs peuvent marquer certaines voitures comme favorites.

Cette fonctionnalité permet de retrouver facilement :

- ses voitures préférées ;
- les véhicules à utiliser pour des événements ;
- les voitures à mettre en avant dans des posts ;
- les modèles importants pour sa progression personnelle.

---

### Wishlist

La wishlist permet de préparer une liste de voitures à obtenir en priorité.

Elle peut servir à suivre :

- les voitures rares ;
- les véhicules recherchés ;
- les voitures nécessaires pour compléter une collection ;
- les modèles que le joueur souhaite acquérir plus tard.

---

## Fonctionnalités communautaires

### Feed

Le feed est l’espace social principal du site.

Il permet aux joueurs de publier du contenu autour de leur progression, de leurs voitures, de leurs photos ou de leurs événements.

Le feed peut accueillir par exemple :

- des publications de progression ;
- des photos de voitures ;
- des présentations de garage ;
- des annonces d’événements ;
- des discussions autour du jeu.

---

### Posts

Les utilisateurs peuvent créer des posts afin de partager leur activité avec la communauté.

Un post peut être utilisé pour :

- montrer une voiture obtenue ;
- partager une photo ;
- annoncer une progression importante ;
- présenter une session en jeu ;
- discuter avec d’autres joueurs.

---

### Likes et commentaires

Les publications peuvent recevoir des likes et des commentaires.

Cela permet de rendre la plateforme plus interactive et de favoriser les échanges entre joueurs.

Les commentaires peuvent servir à :

- réagir à une publication ;
- poser une question ;
- organiser une session ;
- discuter d’une voiture ;
- échanger autour d’un événement.

---

### Abonnés et abonnements

FH6 Tracker intègre un système social basé sur les abonnés et les abonnements.

Les joueurs peuvent suivre d’autres profils pour retrouver plus facilement leur contenu et leur activité.

Cela permet de créer une vraie dimension communautaire autour du tracker.

---

### Posts sauvegardés

Les utilisateurs peuvent sauvegarder des posts pour les retrouver plus tard.

Cette fonctionnalité est utile pour conserver :

- une annonce d’événement ;
- une belle photo ;
- une configuration intéressante ;
- un post important ;
- une information à revoir plus tard.

---

### Événements en jeu

Une des évolutions majeures du projet est l’organisation d’événements communautaires directement via la plateforme.

Les joueurs peuvent créer ou rejoindre des événements en jeu, comme :

- meetings ;
- cruises ;
- sessions photo ;
- rassemblements ;
- défis communautaires ;
- sorties thématiques ;
- événements privés ou publics.

L’objectif est de faire de FH6 Tracker un point de rendez-vous pour la communauté.

---

### Classement

Le classement permet de comparer l’activité et la progression des joueurs.

Il peut mettre en avant différents aspects :

- progression garage ;
- progression Horizon Promo ;
- activité sociale ;
- nombre de posts ;
- nombre d’abonnés ;
- participation communautaire.

Cette fonctionnalité ajoute une dimension compétitive et motive les joueurs à progresser.

---

## Authentification

L’application utilise un système de compte utilisateur.

Une fois connecté, chaque joueur peut retrouver ses propres données :

- garage personnel ;
- photos validées ;
- favoris ;
- wishlist ;
- profil ;
- publications ;
- abonnements ;
- notifications ;
- activité récente.

La progression est donc liée à l’utilisateur connecté.

---

## Notifications et inbox

FH6 Tracker dispose également d’un système de notifications.

L’inbox permet de retrouver les interactions importantes, comme par exemple :

- nouveaux likes ;
- nouveaux commentaires ;
- nouveaux abonnés ;
- interactions sur les posts ;
- informations liées aux événements.

Un compteur de notifications non lues est affiché dans la navigation.

---

## Navigation

Le site est organisé autour de plusieurs sections principales :

- **Dashboard** : vue d’ensemble de la progression ;
- **Catalogue** : liste des voitures et suivi personnel ;
- **Feed** : publications communautaires ;
- **Événements** : organisation et participation aux événements ;
- **Profil** : page personnelle du joueur ;
- **Classement** : comparaison entre joueurs ;
- **Recherche** : recherche globale ;
- **Inbox** : notifications et interactions.

---

## Stack technique

Le projet est développé avec :

- **React** ;
- **TypeScript** ;
- **Vite** ;
- **React Router** ;
- **Tailwind CSS** ;
- **Supabase** ;
- **Lucide React**.

Supabase est utilisé pour gérer l’authentification, les données utilisateurs et les différentes tables liées au projet.
